# Кейс: сбор каталога интернет-магазина в Excel

## Задача

Заказчику нужен актуальный список товаров каталога для офлайн-анализа
и периодического обновления: названия, цены, рейтинг и прямые ссылки —
в одном Excel-файле. Вручную это десятки страниц и часы копирования;
требуется автоматизация.

## Решение

Написан сборщик на Python: он проходит страницы каталога с паузами
(чтобы не нагружать сайт), при временных ошибках повторяет запрос сам,
извлекает карточки товаров и нормализует данные (цены в числовом формате,
рейтинг шкалой 1–5, абсолютные ссылки). Результат — форматированный
Excel-файл: шапка, автофильтр, гиперссылки, числовой формат цен.

Код разбит на модули (сеть/извлечение, экспорт, CLI) и покрыт тестами —
это значит, что логика проверена, а не «запустилось один раз».

## Результат

- 60 записей собрано и выгружено за ~2 секунды (демо: 3 страницы каталога).
- Полный обход 50 страниц — 1000 записей в одном файле.
- Файл открывается в Excel сразу, без доработок: фильтры, сортировка, переходы по ссылкам.

Пример строки отчёта:

| Название | Цена | Валюта | Рейтинг | Ссылка |
|---|---|---|---|---|
| A Light in the Attic | 51.77 | £ | 3 | https://…/a-light-in-the-attic_1000/ |

## Почему это надёжно

- Сборщик вежлив к сайту (паузы, повторы при сбоях) — аккаунт и доступ не под риском.
- Данные можно обновлять повторным запуском одной команды.
- Адаптация под любой каталог = замена селекторов в одном файле.

## Что заказчик получает на руки

1. Итоговый Excel-файл.
2. Инструкцию по повторному запуску обновления данных.
3. Исходный код с тестами (по запросу).
